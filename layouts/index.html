Documentation GitHub

go-ruby-erasure is the pure-Go, Ruby-runtime-independent core of the Ruby erasure gem: a reflective adapter over go-erasure/reedsolomon (Reed-Solomon over GF(216)) and go-erasure/mojette (the Mojette / discrete-Radon transform). A Session exposes both codecs through typed methods returning Ruby-shaped values, plus a single dynamic Call entry point a Ruby binding drives from method_missing. Nothing here depends on the Ruby runtime, so it is equally usable as a standalone Go library. CGO_ENABLED=0, builds for all nine 64-bit targets.

A Ruby-shaped Session

Both codecs behind typed methods and one dynamic Call entry point:

s := erasure.NewSession()
full, _ := s.EncodeRS(2, 2, dataShards)              // []any data+parity
rec,  _ := s.ReconstructRS(2, 2, damaged, present)   // recovered set
projs, _ := s.EncodeMojette(2, 2, 2, gridBlocks, dirs)
out, _ := s.Call(ctx, "reconstruct_rs", 2, 2, damaged, present)
The rbgo require "erasure" binding that wires this adapter into the Ruby interpreter lives in go-embedded-ruby, not in this org.
